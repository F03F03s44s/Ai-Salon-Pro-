# AI SALON PRO

Salon system for **Urban Nail Bar**.

```
AI SALON PRO/
  URBAN NAIL BAR/     ← all app files live here
```

Open [`URBAN NAIL BAR/README.md`](URBAN%20NAIL%20BAR/README.md) to start.

## Pick your computer

| System | Double-click |
|---|---|
| macOS Sierra 10.12.6 | `URBAN NAIL BAR/scripts/EVERYTHING-MACOS-SIERRA-10.12.6.command` |
| macOS High Sierra 10.13 | `URBAN NAIL BAR/scripts/EVERYTHING-MACOS-HIGH-SIERRA-10.13.command` |
| macOS Big Sur 11.7.10+ | `URBAN NAIL BAR/scripts/EVERYTHING-MACOS-BIG-SUR-11.7.10.command` |
| Windows 10 / 11 | `URBAN NAIL BAR/scripts/EVERYTHING-WINDOWS-11.bat` or `START-SALON.bat` |
